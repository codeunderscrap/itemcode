# OCR (scanned PDFs, photographed invoices). Pinned to the classic,
# widely-deployed 2.x line on purpose: paddleocr 3.x + paddlepaddle 3.x's
# new PIR/oneDNN inference backend threw a NotImplementedError on CPU-only
# Windows during testing here (7 August 2026) — a real, reproducible bug,
# not a one-off. 2.x's classic PaddleOCR().ocr() API is what's wired into
# core/ingest.py. Models download once on first real OCR call and are then
# cached under the user's profile (~/.paddleocr) — expect the first scan on
# a fresh machine to be slow (internet required that once), every one after
# that fast and fully offline.
